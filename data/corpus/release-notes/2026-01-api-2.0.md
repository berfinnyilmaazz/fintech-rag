# Release Notes: API 2.0

Released 2026-01.

## Changes
- Payments API v2 is generally available for all merchants.
- Payments API v1 will stop accepting requests on 2026-12-31. Existing v1 integrations keep working until then; no new v1 keys are issued.
- New `requires_action` status on payment intents for 3-D Secure.
