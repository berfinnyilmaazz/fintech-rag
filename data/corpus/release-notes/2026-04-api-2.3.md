# Release Notes: API 2.3

Released 2026-04.

## Changes
- Dispute evidence uploads accept PDF files up to 10 MB.
- Payouts without an `Idempotency-Key` now return a warning header `Vantor-Warning: idempotency-key-required-from-2026-05-11`.
- Fixed: refunds on partially captured intents could exceed the captured amount.
