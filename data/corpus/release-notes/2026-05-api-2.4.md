# Release Notes: API 2.4

Released 2026-05.

## Changes
- `POST /v2/payouts` now requires an `Idempotency-Key`; requests without one fail with `400` and `E4003` (ADR-006).
- `payoutd` deduplicates batch entries before bank submission.
- New error code `E4092` for idempotent requests still in progress.
