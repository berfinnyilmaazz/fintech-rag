# Release Notes: API 2.9

Released 2026-10.

## Changes
- Fixed: SEK processing fees were rounded half-up instead of half-even since 2.8; affected merchants are refunded in the October settlement.
- Instant payouts can be cancelled within 2 seconds with `POST /v2/payouts/{id}/cancel`.
- Restricted keys can be limited to a list of IP ranges.
- Dashboard: chargeback ratio chart per merchant with the 0.9 percent monitoring line.
